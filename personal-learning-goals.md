# Personal Learning Goals

1. **Understand how AI agents actually work** - I use AI tools a lot, but I want to understand what is going on underneath, like how an agent plans, uses tools, and decides what to do next.
2. **Get comfortable with Git and GitHub** - I want to commit, branch, and push without panicking, and keep my projects organized in repositories.
3. **Learn to work in an Agile way** - I want to practice Scrum ideas like sprints and reviews so that group projects are less chaotic.
4. **Use AI responsibly** - I want to know where the risks are (privacy, security, bias, wrong answers) and how to keep a human in control.
5. **Build something real** - By the end of the course I hope to make a small agent-based project that I can show in my portfolio.
